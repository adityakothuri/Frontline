# User Stories

Written as `As a <user>, I want <goal>, so that <reason>.` MVP stories are marked ✅.

## Entry & dashboard

- ✅ As a new user, I want to enter a **demo mode** without full signup, so that I can try
  Watchdog immediately.
- ✅ As a user, I want a calm, clear home dashboard, so that I understand what's happening at a
  glance without feeling alarmed.

## Cameras (simulated)

- ✅ As a user, I want to see my connected/simulated cameras and their status, so that I know
  the system is watching.
- ✅ As a user, I want to open a camera and see a mock feed + event timeline, so that the demo
  feels believable.

## Detection & review (core)

- ✅ As a user, I want to be **notified** (not auto-posted) when AI flags something, so that I
  stay in control of my footage.
- ✅ As a user, I want a review queue of pending detections with type, confidence, time, source,
  and severity, so that I can triage quickly.
- ✅ As a user, I want to open a detection, see the clip/thumbnail and an AI-suggested
  description, and **approve or reject** it, so that only real incidents go public.
- ✅ As a user, I want to **edit the description** and pick an **expiration** before posting, so
  that the public alert is accurate and temporary.

## Public alerts & map

- ✅ As a user, I want an approved detection to become a public neighborhood alert, so that
  nearby people are warned.
- ✅ As a nearby user, I want to see alerts on a map and tap one for details, so that I know
  what's happening around me.
- ✅ As a user, I want expired alerts to disappear, so that the map stays current and relevant.

## Settings & privacy

- ✅ As a user, I want notification, privacy, camera, and default-expiration settings, so that I
  can control my footprint.
- ❌ (Post-MVP) As a user, I want to comment on or react to alerts. See [[Non-MVP Ideas]].
