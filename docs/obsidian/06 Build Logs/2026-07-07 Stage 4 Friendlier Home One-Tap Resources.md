# 2026-07-07 — Stage 4: friendlier home + one-tap resources

## What was built

Reworked the core loop to feel friendlier and faster: details are captured **once at setup**, the
home screen is **warmer**, and tapping a category goes **straight to resources** — no per-category
questions. The guided need-flow screen was removed.

### Removed
- `app/need/[category].tsx` (the urgency/modality/help-type/documents/ZIP guided flow) and its
  `<Stack.Screen name="need/[category]">` registration in `app/_layout.tsx`.

### Profile now stores ZIP
- `src/types/profile.ts` — `VeteranProfile` gains optional `zip?`.
- `src/services/profile/profileStorage.ts` — reads `zip` tolerantly.
- `src/services/profile/ProfileContext.tsx` — `saveFirstName` → **`saveDetails({ firstName, zip })`**
  (merges, preserves `createdAt`). All callers updated.

### Friendlier home — `app/(tabs)/home.tsx`
- Warm greeting hero (time-aware `timeGreeting()` + name) + supportive subtitle + a quiet
  "Showing help near {zip}" line when a ZIP is set.
- **Single-column** `CategoryCard`s: accent-tinted icon chip (48px) + label + one-line description +
  chevron. Replaces the 2-column tile grid.
- Tap → `router.push({ pathname: '/results', params: { category } })` (immediate).

### Category descriptions — `src/types/need.ts`
- `NeedCategoryMeta` gains `description`; a short one-liner filled for all 12 categories (single
  source of truth, reused by the home cards).

### Results build the Need — `app/results.tsx`
- Reads only the `category` param; pulls `zip` from `useProfile()`; fills defaults
  (`this_week` / `either` / `understand` / no docs / radius 15). Verified safe against
  `MockResourceService.search` (`either` = no modality filter; non-`today` sorts by distance).
- Header title = the category label. Empty state action → **"Update location" → `/profile`**.

### Setup + profile capture ZIP
- `app/onboarding.tsx` — added an optional ZIP field (numeric, 5-digit) below the name; calls
  `saveDetails`.
- `app/(tabs)/profile.tsx` — shows + edits **name and ZIP** (via `saveDetails`); keeps Reset setup.

## Checks

- `npm run verify` (typecheck + lint) — **pass** (typed routes auto-regenerated by the running Metro
  dev server after the route file was removed).
- **`expo export --platform ios`** — **pass**: full JS graph bundles cleanly.
- JS-only change — the existing dev build hot-reloaded in the Simulator (no native rebuild; no new
  native deps).

## Notes / scope

- The structured `Need` model and the resource/AI service seams are unchanged — only the **input
  path** changed (defaults + profile instead of a questions screen).
- Results no longer tune ordering per-search (always "this_week" → distance) until optional filters
  are added later. Radius is fixed at 15 (a picker can go in setup/profile later).
- Kept the dark navy base; warmth comes from spacing, rounded cards, greeting, and copy — not
  decorative color (design-system rule preserved).
