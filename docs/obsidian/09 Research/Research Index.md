# Research Index

Home for research notes that inform decisions — library comparisons, integration spikes,
model/provider evaluations. Keep findings here, then feed conclusions into the

## How to use

- One note per research topic: `YYYY-MM-DD <topic>.md`.
- Summarize options, tradeoffs, and a recommendation. Prefer **Context7** for current library
  docs; use `defuddle` to pull clean content from external pages.
- Link the resulting decision in the [[Decision Log]].
